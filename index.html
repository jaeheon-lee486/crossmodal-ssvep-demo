Cross-modal SSVEP — behavioural pilot

Web implementation. Parity id

Colour map and seed fill in from the participant number (map = number mod 2, seed = 100000 + number); override only deliberately. Measure the visible screen width and the eye-to-screen distance — every size in degrees depends on them. The display must be set to 120 Hz; the session refuses to start if the measured refresh cannot carry the chosen frequency plan.

Coherence: % of each colour's dots moving together during a background pulse and during a target pulse (target must be higher). Duty cycle: % of each pulse period that is coherent; 100 = continuous. Speeds: normal applies to every dot except the coherent dots of a target pulse, which move at the burst speed (two independent values, 0–40 °/s). Defaults 50 % / 95 % / 50 %, 5 / 5 °/s (DESIGN_LOG.md, DECISIONS 28–29). Sound preview (default off): in sound trials only, the pips play during cue + gap (1.5 s) and stop when the dots appear — the dots are then silent. Off: pips play during the dots as usual. Trial timing is unchanged either way. All of these are saved with the data.

  • Design:
  • Red and blue dot arrays, one aperture; flicker 13.33 / 12 Hz, coherence pulses 3.33 / 4 Hz
  • Task: press SPACE for stronger coherent sweeps (targets) in the cued colour(s)

Contains flickering visual patterns and sound. Do not run with anyone who has epilepsy, a seizure history, or photosensitivity. Set system volume before starting.
