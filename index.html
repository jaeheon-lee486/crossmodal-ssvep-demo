Cross-modal SSVEP — behavioural pilot

Web implementation. Parity id

Colour map and seed fill in from the participant number (map = number mod 2, seed = 100000 + number); override only deliberately. Measure the visible screen width and the eye-to-screen distance — every size in degrees depends on them. The display must be set to 120 Hz; the session refuses to start if the measured refresh cannot carry the chosen frequency plan.

Coherence: % of each colour's dots moving together during a background pulse. Duty cycle: % of each pulse period that is coherent; 100 = continuous. Normal speed applies to every dot except the coherent dots of a deviant event. Defaults 50 % / 50 % / 5 °/s (DESIGN_LOG.md, DECISIONS 28–29).

Deviant event (target pulse, DECISION 38): four independent layers, all applied together on the same event. Coherence (not below the background) and dot speed (0–40 °/s) of its coherent dots — set them equal to the background values and the event is not distinguishable by motion; luminance dip of that colour's dots (linear-light %, 0 = off); tilt of its coherent direction by ±the angle, random sign per event (0 = off). At least one layer must differ from the background. Defaults 95 %, 5 °/s, 0, 0. Reset motion (default off, DECISION 33): at the end of every coherent window the coherent dots jump back by the distance they swept.

Blocks (DECISION 35): 20 blocks of 20 trials in random order. Attend-one blocks have only red- and blue-cue trials (half each) and never any sound; attend-both blocks have only the red-and-blue cue, with sound on the set % of trials, split evenly between sound matched to the red and to the blue array. Bursts per trial (DECISION 34): the four % must add up to 100; defaults 0 / 90 / 10 / 0; all bursts of a trial are in one colour, the cued one in attend-one blocks (DECISION 37). Sound plays only while the dots are on screen. All of these are saved with the data.

  • Design:
  • Red and blue dot arrays, one aperture; flicker 13.33 / 12 Hz, coherence pulses 3.33 / 4 Hz
  • Task: press SPACE for deviant events in the cued colour(s)

Contains flickering visual patterns and sound. Do not run with anyone who has epilepsy, a seizure history, or photosensitivity. Set system volume before starting.
